# 5. Модули системы

## 5.1 app.py — Главный модуль

**Назначение:** Flask-приложение, маршрутизация, обработка запросов

**Размер:** ~300 строк

**Ключевые функции:**
- `get_current_user()` — получение пользователя из session
- `login()` / `register()` — аутентификация
- `index()` — главная страница
- `task()` / `solve()` — физические задачи
- `math()` / `math_solve()` — математические задачи
- `builder()` / `builder_solve()` — конструктор
- `profile()` — профиль пользователя

## 5.2 models.py — Модели БД

**Назначение:** Работа с базой данных, аутентификация

**Размер:** ~180 строк

**Ключевые функции:**
- `init_db()` — инициализация таблиц
- `hash_password()` — SHA-256 с солью
- `check_password()` — проверка пароля
- `register_user()` — регистрация
- `login_user()` — вход
- `get_user_by_id()` — получение пользователя
- `save_solution()` — сохранение решения
- `get_history()` — получение истории
- `add_xp()` / `add_coins()` — геймификация

## 5.3 tasks.py — Физические задачи

**Назначение:** Решатели физических задач

**Размер:** ~1500 строк

**Разделы:**
- Кинематика (равномерное, равноускоренное движение)
- Динамика (второй закон Ньютона, трение)
- Электричество (закон Ома, мощность)
- Энергия (кинетическая, потенциальная)
- Давление (гидростатическое, Паскаль)
- Термодинамика (теплоёмкость, фазовые переходы)
- Оптика (линзы, преломление)

**Структура задачи:**
```python
{
    'id': 'task_id',
    'name': 'Название',
    'icon': '📊',
    'category': 'Кинематика',
    'color': 'gradient',
    'quantities': {'v': ('Скорость v', 'м/с')},
    'targets': ['v', 't', 'S'],
    'solve': function(known, target)
}
```

## 5.4 math_tasks.py — Математические задачи

**Назначение:** Решатели математических задач

**Размер:** ~400 строк

**Задачи:**
1. Квадратное уравнение
2. Линейное уравнение
3. Система уравнений
4. Площадь треугольника
5. Площадь круга
6. Теорема Пифагора
7. Тригонометрические функции
8. Теорема косинусов
9. Прямоугольный треугольник

**Структура задачи:**
```python
{
    'id': 'task_id',
    'name': 'Название',
    'icon': '📐',
    'category': 'Геометрия',
    'difficulty': '8 класс',
    'condition': 'Описание',
    'formulas': ['формула 1'],
    'inputs': {'a': {'label': 'a'}},
    'unknowns': ['a', 'b'],  # что можно найти
    'solve': function(data)
}
```

## 5.5 loader.py — Загрузчик YAML

**Назначение:** Загрузка задач из YAML-файлов

**Размер:** ~100 строк

**Функции:**
- `TASKS` — глобальный словарь всех задач
- `group_by_category()` — группировка по категориям
- `_load_yaml()` — парсинг YAML

**Источники:**
- `specs/kinematics.yaml`
- `specs/dynamics.yaml`
- `specs/electricity.yaml`
- `specs/energy.yaml`
- `specs/pressure.yaml`
- `specs/thermodynamics.yaml`
- `specs/optics.yaml`

## 5.6 reference.py — Справочник

**Назначение:** Физические константы и формулы

**Размер:** ~80 строк

**Данные:**
- `CONSTANTS` — список констант (скорость света, гравитация и т.д.)
- `FORMULAS` — словарь формул по категориям

## 5.7 graphs.py — Графики

**Назначение:** Генерация SVG-графиков

**Размер:** ~150 строк

**Функции:**
- `generate_graph(type, data)` — генерация SVG
- Поддерживаемые типы: линейные, квадратичные, тригонометрические
