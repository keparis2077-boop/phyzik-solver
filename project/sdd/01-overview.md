# 1. Обзор системы

## 1.1 Назначение

**ФИЗИК** — образовательная веб-платформа для решения задач по физике и математике. Платформа предназначена для учащихся 7-11 классов и предоставляет:

- Решатель задач по физике (7 разделов: кинематика, динамика, электричество, энергия, давление, термодинамика, оптика)
- Решатель задач по математике (алгебра, геометрия, тригонометрия)
- Конструктор задач для самостоятельного составления
- Справочник формул и физических констант
- Система прогресса (XP, монеты, серии)
- История решений
- Тёмная/светлая тема

## 1.2 Целевая аудитория

- Учащиеся 7-11 классов
- Преподаватели (для демонстрации решений)
- Родители (для контроля прогресса)

## 1.3 Ключевые возможности

| Возможность | Описание |
|------------|----------|
| **Решатель задач** | Пошаговое решение с пояснениями |
| **Выбор неизвестного** | Пользователь выбирает, что найти (сторона, угол, площадь и т.д.) |
| **Визуализация** | Графики зависимостей для физических задач |
| **Геймификация** | XP, монеты, уровни, серии |
| **Конструктор** | Создание пользовательских задач |
| **Адаптивность** | Работа на мобильных устройствах |
| **Тёмная тема** | Переключение темы оформления |

## 1.4 Технические требования

- **Python:** 3.13+
- **Flask:** 3.0+
- **SQLite:** 3.36+
- **Браузер:** Chrome 90+, Firefox 88+, Safari 14+

## 1.5 Структура проекта

```
project/
├── app.py              # Главный Flask-приложение
├── models.py           # Модели БД и аутентификация
├── tasks.py            # Физические задачи
├── math_tasks.py       # Математические задачи
├── loader.py           # Загрузка задач из YAML
├── reference.py        # Справочник формул и констант
├── graphs.py           # Генерация графиков
├── specs/              # YAML-спецификации задач
├── templates/          # HTML-шаблоны
├── static/             # CSS, JS, изображения
├── tests/              # Модульные тесты
├── history.db          # База данных SQLite
└── sdd/                # Документация (SDD)
```
