# 2. Архитектура системы

## 2.1 Общая архитектура

Система построена по классической MVC-архитектуре (Model-View-Controller) с элементами MTV (Model-Template-View) фреймворка Flask.

                           │ Form POST

## 2.2 Слои системы

### 2.2.1 Presentation Layer (UI)

- **Шаблоны Jinja2:** base.html, index.html, task.html, math_task.html и др.
- **CSS:** Современный дизайн с CSS-переменными, анимациями, адаптивностью
- **JavaScript:** Ванильный JS (без фреймворков), обработка форм, валидация, тема

### 2.2.2 Application Layer (Flask Routes)

- **app.py:** 20+ маршрутов, обработка GET/POST запросов
- **Session-based auth:** Аутентификация через cookies
- **Flash messages:** Уведомления пользователей

### 2.2.3 Business Logic Layer

- **tasks.py:** 30+ физических задач с решателями
- **math_tasks.py:** 8 математических задач с решателями
- **loader.py:** Загрузка YAML-спецификаций
- **reference.py:** Константы и формулы
- **graphs.py:** Генерация SVG-графиков

### 2.2.4 Data Access Layer

- **models.py:** CRUD операции, хэширование паролей, миграции БД
- **SQLite:** File-based database, ACID-compliant

## 2.3 Паттерны проектирования

| Паттерн | Где применяется |
|---------|----------------|
| **Factory** | loader.py — создание задач из YAML |
| **Strategy** | Каждый решатель задачи — отдельная функция |
| **Singleton** | get_db() — подключение к БД |
| **MVC/MTV** | Разделение логики, представления и данных |
| **Dependency Injection** | request.form передаётся в решатели |

## 2.4 Внешние зависимости

```
Flask==3.1.1
```

## 2.5 Интеграции

- **MathJax 3:** Рендеринг математических формул (CDN)
- **SQLite 3:** Встроенная БД
